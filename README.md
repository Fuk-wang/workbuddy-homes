# WorkBuddy 展示站 · 站内说明

单页产品展示站，整个站点就是根目录这一个 `index.html`：样式、图标（内联 SVG）、
交互脚本全部写在里面，不引用 CDN、外部字体和外部图片。双击就能离线打开。

线上地址：https://fuk-wang.github.io/workbuddy-homes/
仓库：Fuk-wang/workbuddy-homes（公开，本目录即仓库根目录，Pages Source = main / (root)）

内容性质：课程练习用的**非官方**演示页，产品与命令按腾讯 WorkBuddy / CodeBuddy 官方文档
整理（2026-10-20 核对），页面顶部有「非官方演示页」声明条，正文里标注了来源地址。

本地打开
-----------------------------------------------------
- 直接双击 index.html（file:// 打开也完全正常，这是设计场景）
- 想在 http 下预览：在本目录跑 `python -m http.server 8942 --bind 127.0.0.1`，
  然后访问 http://127.0.0.1:8942/index.html（用完记得关掉这个服务器）

页面结构（对应需求清单，七个板块）
-----------------------------------------------------
0. 顶部非官方声明条：说明内容性质与来源，避免被当成官方文档
1. 顶部固定导航：首页 / 功能特性 / IMA知识库教程 / 使用指南 / 命令行参考，
   点击平滑滚动 + 当前板块高亮
2. 首屏英雄区：主标题、副标题、主按钮「看看怎么上手」与次按钮「知识库怎么接」，
   右侧纯 CSS 桌面端窗口示意图（新建任务 → 产物）
3. 功能特性：4 张卡片（一句话下任务 / 桌面端 + 手机 / 十余款模型可换 / 接你自己的资料），
   悬停上浮加深阴影
4. 核心功能 IMA 知识库对接：前置条件 → 操作步骤 → 效果说明，三个 tab 切换带过渡动画，
   每个 tab 内有「检查 / 提示 / 对比」小卡
5. 使用指南：左「桌面端（图形界面）」5 步、右「命令行（CodeBuddy Code）」分栏；
   CLI 代码块带「一键复制」按钮，复制后按钮变「已复制」并弹 toast
6. 命令行参考：6 条可折叠项（codebuddy / codebuddy -p / 管道输入 / codebuddy -c /
   /init · /model / codebuddy update），点标题展开参数表与调用示例；开头有
   「WorkBuddy 没有官方 CLI，命令行工具是另一款产品」的提示条
7. 页脚：项目名、版权（年份脚本自动取当前年）、页面导航与说明

改法
-----------------------------------------------------
- 文案、卡片、命令参数都在 `index.html` 里，按注释小节改即可（样式在 `:root`
  设计变量里统一控制：深灰 `--gray` 系 + 蓝绿 `--teal` 系）。
- 小字颜色（`--muted` / `--faint`、深色块里的注释色）已按 WCAG AA 调到 4.5:1 以上，
  再改浅会掉回不达标，改前先量对比度。
- `.acc-inner .usage` 是 div 不是 pre，靠 `white-space:pre-wrap` 保留换行，
  别删这条，否则代码块会被挤成一行。
- 改完 `git add -A && git commit -m … && git push`，几十秒后线上自动更新；
  浏览器可能还显示旧版，Ctrl+F5 强刷。
